# CNN Image Recognition

Sistema educacional de reconhecimento de imagens usando MobileNetV2 e Gradio. A Space usa um runtime fixado para manter compatibilidade entre Gradio, NumPy e TensorFlow.

## Como usar

1. Faça upload de uma imagem
2. Aguarde a análise
3. Veja as top 5 previsões com porcentagem de confiança

## Tecnologias

- TensorFlow 2.x
- MobileNetV2 (ImageNet)
- Gradio Interface
- Python 3.11
